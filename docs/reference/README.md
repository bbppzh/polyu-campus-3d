# 四棟建築外觀參照

核對日期：2026-10-18。來源用於辨認輪廓及構成，不代表已取得可量度的施工圖。以下最終模型預覽取代同資料夾舊版 `model-*`／`official-*-crop` 配對；舊圖只保留作歷史檢查記錄。

- **LKS**：[Wong Tung 建築師專案](https://www.wongtung.com/en/projects/li-ka-shing-tower-the-hong-kong-polytechnic-university/)。官方照片及文字顯示相互交接的幾何樓體、較高平頂翼及頂部行政圓筒。模型以照片估計平面比例；60.8 m 不是經本次核實的實測高度。
- **JCIT**：[Zaha Hadid Architects 專案及竣工外觀照片](https://www.zha.com/projects/architecture/jockey-club-innovation-tower?disclaimer=true)，攝影 Iwan Baan；核對兩個相反方向的外觀。長形曲面、白色橫帶、斜冠及外展底座由照片辨認。[CVU／CTBUH 記錄](https://www.skyscrapercenter.com/building/the-jockey-club-innovation-tower/15985) 列出 71.2 m、15 層。
- **Hotel ICON**：[Rocco Design 專案](https://www.rocco.hk/cms/projects/teaching-hotel-complex-the-hong-kong-polytechnic-university/)，照片及分解圖辨認有稜角的酒店、教學部分、空中凹層、會議低座及職員宿舍。[CVU／CTBUH 記錄](https://www.skyscrapercenter.com/building/hotel-icon/13241) 列出建築／頂尖高度 114 m、28 層；最高使用樓層為 103 m。樓層數不是本模型的高度換算公式。
- **Z 座**：[理大官方相片庫](https://www.polyu.edu.hk/en/photo-gallery/)，外觀照片 [C0088](https://www.polyu.edu.hk/-/media/department/home/gallery/campus-environment/c0088.jpg) 及中庭照片 [C0132](https://www.polyu.edu.hk/-/media/department/home/gallery/campus-environment/c0132.jpg)。核對雙翼、低座、連橋、磚牆與窗洞。[工程承辦商記錄](https://www.wongpokee.com/service/new-development-projects) 描述兩座 12 層及一座 4 層樓體。48 m 高翼及各平台標高仍屬視覺估計。

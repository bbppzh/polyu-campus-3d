A low-poly, interactive 3D study of the Hong Kong Polytechnic University's Hung Hom
campus, built with [Three.js](https://threejs.org/). The massing comes from real
OpenStreetMap building footprints; names, categories and tour photography come from
PolyU's official [virtual campus tour](https://www.polyu.edu.hk/saso/vtour/).

![Campus in Massing](docs/day.png)

## Run it

```bash
cd polyu-campus-3d
python3 -m http.server 8123
# open http://localhost:8123
```

No build step, no network access, no API keys. Three.js is vendored in `vendor/three/`.
(`./serve.sh` does the same thing on port 8123, or 8080 with `npm run serve`.)

Useful URL parameters: `?t=0.9` opens at a given time of day (0 = midnight,
0.5 = noon, 0.75 = sunset), `?select=library` opens with that landmark's card,
`?q=block` / `?cat=Sports` pre-filters the finder, `?cam=x,y,z&target=x,y,z` sets a
specific viewpoint, `?pano=1` with `select` opens the 360° view directly, and
`?embed=1` strips the UI down to the slowly rotating scene.

## Controls

| Action | Control |
| --- | --- |
| Orbit | drag on the scene |
| Pan | right-drag, or drag directly on the minimap |
| Zoom | scroll / pinch |
| Find a place | search box + category chips in the top-left panel |
| Minimap | bottom-right plan view: camera direction, drag to pan, click to jump |
| Labels | show / hide building labels |
| Time of day | slider (default 10:05) |
| Orbit | slow auto-rotation |
| Reset | return to the opening view |

Click (or tap) a labelled building to open its card: a 360°-tour still, the building's
height and type, a short description, and a link to the official tour.

For the 12 landmarks with a matched tour panorama, the card also has **Enter 360°
view**: a full-window, draggable panorama built from the tour's photo-cube faces
(stitched into an equirectangular texture at runtime). Drag to look around, scroll to
zoom, Esc closes. Deep link: `?select=library&pano=1`.

## What is in the scene

- **30 landmark buildings**, generated by extruding their OSM footprints, including
  Jockey Club Innovation Tower, Pao Yue-kong Library, Jockey Club Auditorium, Li Ka
  Shing Tower, Hotel ICON, Blocks X and Z, Industrial Centre, Communal Building, Shaw
  Sports Complex, Lee Shau Kee Building, Tang Ping Yuan Building, the student hub and
  the surrounding named academic buildings.
- **PBR facades**: real CC0 brick and sandstone textures (diffuse + normal +
  roughness) tinted to PolyU's palette, with procedural punched/ribbon windows,
  mullions, storey bands, stone plinths, ground-floor shopfront glazing and roof parapets.
- **Landmark-specific form**: custom GLBs for all 30 named buildings. The latest
  four are LKS (interlocking straight blocks and an elevated executive drum),
  JCIT (71.2 m envelope, layered curved slab and sloping crown), Hotel ICON
  (114 m envelope, angular hotel/teaching wings and recessed sky level), and
  Block Z (two high wings, a low teaching block, terraces and a sky link).
  Other models include the Auditorium shell, Library entrance glazing and the Block X setback massing.
- **Entrance signage**: canvas-rendered building signs with the PolyU red band, English
  name and Chinese name, mounted above the main entrance of all 30 named buildings.
- **Campus fabric**: the connected podium buildings around the core, in PolyU's
  red-brick and stone palette, with the surrounding Hung Hom city block massing
  muted behind it (~400 buildings).
- **Context detail pass**: surrounding buildings use brick, stone or city tones,
  perimeter parapets and checked ground-floor shopfront/awning strips, merged by
  material. The rendering footprints resolve overlapping source building records.
- **Ground**: roads, footpaths, steps, pitches, gardens and pools from OSM,
  plus 170 procedurally placed trees with building and road clearance.
- **Atmosphere**: Victoria Harbour with a gentle swell, a hazy Hong Kong skyline ring,
  and a dawn/day/sunset/night sky with lit windows at night.

## Data pipeline

`data/campus.json` is generated by `tools/extract_data.py` from:

- `_recon/buildings.json`, `_recon/roads.json`, `_recon/landuse.json` — OpenStreetMap
  data for the campus bounding box, fetched with Overpass.
- `/tmp/polyu/en.txt` + `script_general.js` — the 3DVista export of PolyU's 360° tour,
  used for landmark names, categories and panorama thumbnails.

Projection: local metres with origin (22.3045 N, 114.1795 E); x = east, z = south.
Building height = OSM `height` → `building:levels × 3.2 m` → type-based default.
To regenerate after changing the inputs: `python3 tools/extract_data.py`.

The JCIT shell is generated parametrically and finished in Blender:

```bash
python3 tools/build_jcit.py      # procedural base shell → assets/models/jcit.glb
# Blender: open the GLB, shade smooth by angle, export the GLB
# the editable result is saved at assets/models/jcit.blend
```

It is a stylised approximation of Zaha Hadid's design — a lofted asymmetric shell
with glazing ribbons, a leaning crown and a compact glazed podium — not an official
CAD model. The GLB is a standard glTF 2.0 binary and can be edited further in Blender;
the app falls back to the in-code version if the GLB is missing.

## Collision fixes — 2026-10-19

JCIT now fits its long axis to the mapped compound rather than a single perimeter
edge; its arbitrary lateral offset is removed. The auditorium roof is clipped to
the hall perimeter, and the Student Hub's adjoining walls are trimmed at Chow Yei
Ching / Yip Kit Chuen. Original geographic records remain in `data/campus.json`.

`data/scene-layout.json` is a derived rendering layout. It removes overlapping
background building volumes, supports holes in the remaining footprints, and
keeps entire tree crowns clear of buildings and roads. Generic awnings are checked
by polygon containment and edge crossings. Heights and architectural proportions
remain approximations; see [the detailed check record](docs/COLLISION-FIX-20261019.md).

After changing any landmark GLB or the source map, regenerate the layout before
publishing (Python needs `tools/requirements-geometry.txt`):

```sh
python3 tools/build_scene_layout.py
node tools/check_scene_layout.mjs /tmp/campus-details.json
python3 tools/check_scene_intersections.py /tmp/campus-details.json
python3 tools/check_model_intersections.py
python3 tools/audit_models.py
python3 tools/check_hotel_entrances.py
```

The layout check rejects stale model/source hashes. `tools/rebuild_all.py` only
rebuilds models; run the commands above afterwards.
